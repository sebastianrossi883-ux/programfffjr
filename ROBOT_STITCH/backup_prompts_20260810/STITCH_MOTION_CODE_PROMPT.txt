## 0B. ATTIVAZIONE DEL GUEST ESCLUSIVAMENTE TRAMITE SCROLL (FATAL LAW)
1. Il Guest Component deve essere DORMIENTE al caricamento iniziale della pagina.
2. La root del Guest deve contenere esattamente:
   `data-motion-activation="scroll"` e `data-motion-mounted="false"`.
3. Definisci la funzione originale di mount, ma invocala UNA SOLA VOLTA esclusivamente:
   - dentro `ScrollTrigger.create({ trigger: guestRoot, onEnter: ... })`; oppure
   - dentro un callback `IntersectionObserver` quando `entry.isIntersecting === true`.
4. Dopo il mount riuscito imposta `data-motion-mounted="true"` e usa un guard
   booleano o lo stesso attributo per impedire inizializzazioni duplicate.
5. È VIETATO invocare il mount direttamente a livello globale, in
   `DOMContentLoaded`, `window.load`, `setTimeout` o `setInterval`.
6. L'unica eccezione è un componente nativo CSS scroll-driven che utilizza davvero
   `animation-timeline`, `scroll-timeline` o `view-timeline`: anche in quel caso la
   root deve mantenere `data-motion-activation="scroll"`.
7. Il componente non deve riprodursi, avanzare o animarsi prima che la sua sezione
   entri nel viewport. La stessa regola vale su desktop, mobile e touch.

7. Questo comportamento del menu e il gate scroll del Guest sono indipendenti:
   nascondere l'header non deve montare anticipatamente il Guest Component.

## 2. NATIVE MODULE INJECTION (THE <SCRIPT TYPE="MODULE"> MANDATE)
Quando assembli il sito in un file HTML statico, per far funzionare i componenti Framer o React:
1. **DEVI** inserire il tag `<script type="module">` nativo.
2. **DEVI** importare il file sorgente originale `.mjs` o il bundle React fornito, senza alterarne il codice.
3. **DEVI** creare i container di idratazione DOM (`<div id="framer-root"></div>`) esattamente come richiesto dal sorgente, senza inquinarli con classi Tailwind che alterano il Box Model.

## 3. DOM HIERARCHY PRESERVATION (CODROPS & GSAP PLUGINS)
Per componenti Codrops complessi (es. RevealSlideshow) e plugin premium GSAP:
1. **VIETATO ROMPERE IL DOM**: Inietta l'esatta struttura HTML (genitore/figlio) richiesta dal componente. Se il WebGL originale richiede 12 `div` annidati, li scrivi tutti e 12. Non riassumerli in un singolo `div`.
2. **NESSUNA MASCHERA CSS FINTA**: Usa il codice matematico originale (es. spring physics, calcoli WebGL o matrici 3D). Non sostituire la fisica originale con transizioni `opacity: 0` o `transition-all`.

## 4. THE "ANTI-WHITE SCREEN" QUARANTINE
Sappiamo che importare moduli complessi in un singolo HTML può creare conflitti. 
La tua soluzione **NON È** cancellare il componente e fregarmi mettendoci un GSAP finto. 
La tua soluzione è **LA QUARANTENA**:
- Isola il componente in un container protetto (`position: relative; z-index: 50; overflow: hidden;`).
- Non usare `document.querySelectorAll` globali che confliggono con altri componenti. Limita l'azione degli script al loro container specifico.
